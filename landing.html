Mulai dalam 3 langkah

Nggak ada SDK, nggak ada registrasi berlapis. Key, request, jalan.

  1. 01

    Buat API key

    Di dashboard, buka halaman + Tambah, isi nama akun, klik Buat akun. Satu akun Muse = satu API key. Prompt reporter otomatis disalin — kirim ke Muse di mesin tempat akun itu login supaya kuota real-nya kelapor tiap 30 menit.

  2. 02

    Kirim request

    POST /v1/chat/completions dengan header Authorization: Bearer <key>. Formatnya OpenAI-compatible, streaming SSE didukung — colok ke 9Router atau tool favorit lu langsung jalan.

  3. 03

    Kuota ngikutin akun

    Dashboard baca subscription asli tiap akun: weekly limit, tanggal reset, additional tokens. Kuota habis? Request ditolak 429 — bukan error misterius.
